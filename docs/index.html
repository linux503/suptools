SupTools超级工具箱

为 Mac 打造的一站式系统工具：监控、清理、卸载、启动项、截图录屏，开箱即用。

开始安装 查看引导

Tools

六个常用工具，一个窗口搞定

侧栏按「监控 / 工具 / 设置」分组。下面是工具区每一项在做什么，以及你需要开通的权限。

01

清理

扫描缓存、浏览器、开发工具、Docker、大文件与废纸篓；默认勾选安全项，谨慎项手动确认。

02

卸载

列出已安装应用，查找偏好设置、缓存、容器等关联残留，移至废纸篓或彻底删除。

03

启动项

管理登录项与 LaunchAgent，一键关闭开机自启；系统级项目可跳转系统设置。

04

截图 / 录屏

框选、窗口、全屏截图与录屏，支持标记编辑、麦克风与全局快捷键。

05

连通性

一键检测 DNS、TCP、HTTP 延迟，快速判断网络是否畅通。

06

权限引导

集中检测屏幕录制、辅助功能、麦克风、完全磁盘访问等；开启后显示「已开启」成功状态。

Guide

三步开始使用

装好应用后，先把推荐权限开齐，功能会稳定很多。

安装到「应用程序」

运行打包脚本，或把 SupTools.app 拖进 /Applications，然后打开。

打开「工具 → 权限」

逐项点「去开启 / 请求授权」，在系统设置勾选 SupTools；返回后会自动检测并提示成功。

按需使用工具

清理与卸载建议开启完全磁盘访问；截图录屏需要屏幕录制；全局快捷键需要辅助功能。

Install

从源码安装

需要 Python 3.9+ 与 macOS 13+。克隆仓库后一键打包安装到 /Applications。

# 克隆
git clone https://github.com/linux503/suptools.git
cd suptools
 
# 依赖（开发运行）
python3 -m pip install -r requirements.txt
 
# 打包并安装到「应用程序」
./Scripts/install-to-applications.sh
在 GitHub 查看源码 回到顶部
