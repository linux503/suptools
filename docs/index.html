SupTools超级工具箱

Mac 常用工具合集：看状态、清空间、卸软件、管启动项、截图录屏。

功能

就这几样

不做花哨面板，只保留日常真正会点的功能。

  • 01
    总览CPU、内存、网络、磁盘，以及占用最高的进程。
  • 02
    清理扫描缓存、浏览器、开发文件和废纸篓，勾选后清理。
  • 03
    卸载删除应用，并尽量扫掉关联残留。
  • 04
    启动项关闭登录自启与 LaunchAgent。
  • 05
    截图 / 录屏框选、窗口、全屏；支持标记与快捷键。
  • 06
    权限一次性检查并打开系统隐私权限。
